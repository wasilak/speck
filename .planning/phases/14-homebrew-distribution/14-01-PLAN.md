<objective>
Fix the release.yml CI pipeline to produce a properly signed and notarized .pkg artifact:
(1) add --timestamp to the existing binary codesign step (required by notarytool),
(2) add a Developer ID Installer certificate import step to build.keychain,
(3) replace the broken zip/staple-to-binary/tar.gz distribution chain (lines 58–97) with pkgbuild + notarize + staple-to-pkg + gh release create + tap Cask SHA256 auto-update + keychain cleanup.

Purpose: The current release.yml has three latent bugs: (a) --timestamp is missing from codesign — notarytool rejects the submission with "binary was not built with the hardened runtime + timestamp"; (b) xcrun stapler targets the bare binary — unsupported, stapler only works on .pkg/.app/.dmg/.xar; (c) distribution via tar.gz causes Homebrew to re-sign the binary with an ad-hoc cert, orphaning the Developer ID chain. Switching to .pkg preserves the full chain because installer -pkg does not re-sign.

Output: .github/workflows/release.yml with corrected signing, pkg-based notarization, and SHA256 computed post-staple.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Secrets → CI runner | Private key material (.p12 files, auth_key.p8) crosses at import time |
| CI runner → Apple notarization API | auth_key.p8 credentials sent to Apple CDN |
| CI-produced .pkg → user machines | Package integrity must be verifiable offline via stapled notarization ticket |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Information Disclosure | /tmp/build.p12, /tmp/installer.p12, auth_key.p8 | mitigate | Decode only to runner-local /tmp or working dir; `rm -f auth_key.p8` after notarytool completes; keychain deleted in `if: always()` cleanup step — keys never committed to repo |
| T-14-02 | Tampering | .pkg artifact SHA256 | mitigate | SHA256 computed AFTER `xcrun stapler staple`; any post-staple modification changes the hash and `brew install` fails the SHA256 check |
| T-14-03 | Tampering | notarization ticket | accept | Apple CDN delivers tickets; staple embeds ticket in .pkg container; `codesign --verify` detects tampering after staple; low risk given Apple's CDN security |
| T-14-04 | Repudiation | CI runner keychain state | mitigate | `if: always()` cleanup ensures build.keychain is deleted regardless of step failure; no persistent keychain state leaks to subsequent jobs |
| T-14-SC | Tampering | npm/pip/cargo installs | accept | Phase 14 installs no new packages; all tooling is Apple system tools pre-installed on macos-latest runners |
</threat_model>
