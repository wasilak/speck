CheckResult enum: derive Debug, PartialEq, Eq. Four variants — Pass (unit), Fail { hint: String }, Warn { detail: String }, Skip { reason: String }.

print_check(label: &str, result: &CheckResult): match on all four variants using println!. Pass: "  {GREEN}PASS{RESET}  {label}". Fail: "  {RED}FAIL{RESET}  {label}\n         hint: {hint}". Warn: "  {YELLOW}WARN{RESET}  {label}\n         {detail}". Skip: "  SKIP  {label} ({reason})".

check_codesign() -> CheckResult: get binary path via std::env::current_exe(). Spawn std::process::Command::new("codesign") with args ["-d", "--entitlements", "-", &binary_path.to_string_lossy()]. Combine stdout and stderr into one string (PITFALL 1 from RESEARCH.md: codesign routes output to either stream depending on macOS version). If combined contains "com.apple.security.virtualization" return Pass. If command succeeds but string absent return Fail { hint: "Binary missing virtualization entitlement — run `cargo xtask codesign-dev`" }. If command fails to spawn return Warn { detail: "codesign not available (expected on macOS)" }.

check_docker_host(speck_home: &Path) -> CheckResult: compute expected = format!("unix://{}", speck_home.join("speck.sock").display()). Read DOCKER_HOST from std::env::var. If matches expected return Pass. If present but different return Warn { detail: format!("DOCKER_HOST={val} (expected {expected}) — run `eval $(spk env)` or check for another active runtime") }. If absent return Warn { detail: "DOCKER_HOST not set — run `eval $(spk env)` or `spk init`".into() }.

check_cert_injection(speck_home: &Path) -> CheckResult: call crate::config::load_config_file(speck_home). On error return Warn { detail: format!("cannot read config: {e}") }. If app_config.ca.extra_certs is empty return Skip { reason: "no CA certs configured".into() }. For each path_str in extra_certs: read file contents with std::fs::read(path_str); on error return Fail { hint: format!("configured cert source not found: {path_str}") }. Compute hash_hex = format!("{:x}", Sha256::digest(&content)). Check speck_home.join("ca-certs").join(format!("{hash_hex}.pem")).exists(); if missing return Fail { hint: format!("cert {path_str} not staged — run `spk up` to reinject") }. Return Pass after all certs verified.

check_vm_resources(speck_home: &Path) -> CheckResult: call crate::commands::up::read_vm_resource_snapshot(speck_home). On Ok(Some(cfg)) println!("         cpus: {}, memory: {} MiB, disk: {} GiB", cfg.cpus, cfg.memory_mb, cfg.disk_gb) then return Pass. On Ok(None) return Skip { reason: "vm-config.json not found (daemon not started yet)".into() }. On Err(e) return Warn { detail: format!("cannot read vm-config.json: {e}") }.

check_public_dns() -> CheckResult: use std::net::ToSocketAddrs. Call "google.com:443".to_socket_addrs(). If Ok(addrs) and addrs.count() > 0 return Pass. Otherwise return Fail { hint: "public DNS resolution failed — check network connectivity".into() }.

check_vpn_dns() -> CheckResult: call speck_net::read_resolver_table_once(). If table.is_empty() return Skip { reason: "no VPN-scoped resolvers detected (no VPN active)".into() }. Otherwise return Pass. Note: speck_net::read_resolver_table_once() and ResolverTable::is_empty() are added in Task 2; add the call now so the file compiles once Task 2 completes.
