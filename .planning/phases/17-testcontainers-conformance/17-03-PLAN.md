    **Change**: Load port bindings from storage and inject them:

    1. The function currently takes parameters like `container_id`, `name`, `image`, `status`, etc. If it already has access to the state/AppState, add a storage call. If not, thread `storage: &Arc<tokio::sync::Mutex<crate::storage::Storage>>` as a parameter.

    2. In the function body, add:
    ```rust
    let port_bindings_map: HashMap<String, Value> = if let Ok(storage) = state.storage.lock() {
        match storage.load_port_bindings(id) {
            Ok(Some(pb)) => pb.into_iter().map(|(k, v)| {
                // Docker API expects port bindings in format: { "80/tcp": [{ "HostIp": "0.0.0.0", "HostPort": "8080" }] }
                (k, serde_json::to_value(v).unwrap_or(Value::Null))
            }).collect(),
            _ => HashMap::new(),
        }
    } else {
        HashMap::new()
    };
    ```

    3. Replace the empty `Ports` initialization with:
    ```rust
    "Ports": serde_json::Value::Object(serde_json::Map::from_iter(port_bindings_map.into_iter())),
    ```
