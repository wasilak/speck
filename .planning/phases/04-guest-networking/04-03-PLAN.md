<objective>
Wire the virtual network device into the VM configuration using `VZFileHandleNetworkDeviceAttachment` + `VZVirtioNetworkDeviceConfiguration`.

**Purpose:** During `VmThread::do_start()`, after the vsock device is configured and before `validateWithError`, create a datagram socketpair, give one end to the VM as a `VZFileHandleNetworkDeviceAttachment` via `VZVirtioNetworkDeviceConfiguration`, and store the host end for the netstack task. This is the hardware wiring — the netstack (Plan 02/04) will be the driver that reads/writes frames on the host end.

**Output:** Updated `speck-vz/Cargo.toml` (feature flags + socket2 dep), `error.rs` (Network variants), `config.rs` (GuestConfig.network field), `vm_thread.rs` (socketpair creation + attachment wiring + host_fd storage).
</objective>

       self.sender
           .blocking_send(VmCommand::NetstackFd { reply: tx })
