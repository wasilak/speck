<objective>
Implement TCP re-origination, DHCP server, vsock-based DNS proxy, and MTU/MSS clamping.

**Purpose:** Four pieces complete the networking: (1) **TCP re-origination** bridges each guest TCP connection to a real host `TcpStream` so guest traffic egresses from the host's network namespace; (2) **DHCP server** listens on smoltcp UDP port 67 and responds to guest DISCOVER/REQUEST with OFFER/ACK providing IP 172.16.0.2, gateway 172.16.0.1, and DNS server 172.16.0.1 (per D-05); (3) **vsock-based DNS proxy** reads length-prefixed DNS wire-format queries arriving over a vsock fd (not L2 frames), resolves via `getaddrinfo`, and sends responses back — honoring system resolver, split-DNS, and live VPN DNS changes (per D-07); (4) **MTU detection** reads the host interface MTU and configures smoltcp MSS accordingly. Reorigin, DHCP, and MTU are wired into the `SpeckNet::spawn()` poll loop; the DNS proxy runs as a separate vsock-driven tokio task.

**Output:** `reorigin.rs`, `dhcp.rs`, `dns.rs`, `mtu.rs`, updated `lib.rs` (wire modules into SpeckNet + expose spawn_dns_proxy).
</objective>

   ```rust
   use smoltcp::socket::tcp;
   use smoltcp::iface::SocketSet;
   use std::collections::HashMap;
   use std::net::TcpStream;
   use std::io::{Read, Write};

   pub(crate) struct ReoriginBridge {
       /// Maps smoltcp socket handle → host TcpStream
       bridges: HashMap<tcp::SocketHandle, TcpStream>,
       /// Maximum number of concurrent bridged connections
       max_bridges: usize,
   }
   ```

2. Constructor: `pub fn new() -> Self` with empty bridges HashMap and max_bridges = 256.

3. `pub fn poll_bridges(&mut self, sockets: &mut SocketSet)`:
   - Iterate over `self.bridges` (clone handles to avoid borrow issues).
   - For each (handle, stream):
     - Get the smoltcp socket via `sockets.get_mut::<tcp::Socket>(handle)`.
     - If socket is closed (`!socket.is_open()`), close the stream (`stream.shutdown(Shutdown::Both)`), remove from bridges map.
     - Bridge data guest→host: if `socket.can_recv()`, read from smoltcp socket with `recv_slice`, write to host stream with `write_all`.
     - Bridge data host→guest: set stream non-blocking, read from stream with `read`. On Ok(0) → close guest socket. On Ok(n) → write to smoltcp socket with `send_slice`. On WouldBlock → continue. On other error → close guest socket.
   - Follow the RESEARCH.md pattern exactly: poll_bridges should be called after `iface.poll()` in the main loop.

4. `pub fn handle_new_connections(&mut self, sockets: &mut SocketSet)`:
   - Iterate over sockets in the set to find `tcp::Socket`s that are in `ESTABLISHED` state.
   - For each established socket that is NOT already in `self.bridges`:
     - Get its remote endpoint (`socket.remote_endpoint()`).
     - If the endpoint is not a loopback address (127.0.0.0/8):
       - Create a host `TcpStream::connect(remote_endpoint)`.
       - If successful, store in `self.bridges`.
       - If connection fails, close the guest socket.

5. `pub fn bridge_count(&self) -> usize` — returns `self.bridges.len()`.

6. Imports: `use std::io::{Read, Write, ErrorKind};`, `use std::net::{TcpStream, Shutdown};`, `use smoltcp::socket::tcp;`

Note on the "established socket detection" approach: After `iface.poll()`, smoltcp processes the TCP handshake. The socket transitions to ESTABLISHED state. `socket.is_open()` returns true when a connection is established. We can iterate `sockets.iter()` to find TCP sockets that are open but not yet bridged.

Use the smoltcp approach: iterate socket set, find TCP sockets with `socket.state() == tcp::State::Established` that aren't in bridges map. For each, create host `TcpStream::connect`.

3. `pub fn add_to_set(&mut self, sockets: &mut SocketSet)`:
   - Create `udp::PacketBuffer` with rx_buffer of 1 metadata slot + 548 bytes (DHCP min size), tx_buffer same.
   - Create `udp::Socket::new(rx_buffer, tx_buffer)`.
   - Bind to port 67 (`socket.bind(67).unwrap()`).
   - Store the handle.

4. `pub fn poll(&mut self, sockets: &mut SocketSet)`:
   - Get the UDP socket. If no handle, return.
   - If `socket.can_recv()`:
     - Receive the packet with `socket.recv()`. The socket must be set to allow receiving from any port (accept broadcasts).
     - Parse the DHCP message type from the first 240+ bytes:
       - Byte 0: op (1=BOOTREQUEST)
       - Bytes 1-3: htype/hlen/hops
       - Bytes 4-7: xid (transaction ID — save for response)
       - Bytes 28-31: ciaddr (client IP, 0 for DISCOVER)
       - Bytes 44-47: siaddr (server IP)
       - Bytes 236+: options (magic cookie 0x63825363 then TLVs)
     - Scan options for DHCP message type (option 53):
       - 1 = DISCOVER → respond with OFFER
       - 3 = REQUEST → respond with ACK
       - Other → drop silently
     - For **DISCOVER** (type 1):
       - Build OFFER response with `socket.send_slice()`:
         - op=2 (BOOTREPLY), htype=1, hlen=6, xid=from request
         - flags=broadcast, ciaddr=0, yiaddr=self.offered_ip, siaddr=self.server_ip, giaddr=0
         - chaddr=from request (first 16 bytes of options space)
         - Magic cookie 0x63825363
         - Options: DHCP message type=OFFER(2), Subnet mask=self.subnet_mask, Router=self.gateway_ip, DNS=self.dns_ip, Lease time=self.lease_time_secs, Server identifier=self.server_ip, End marker(255)
       - Set destination to 255.255.255.255:68 (broadcast)
     - For **REQUEST** (type 3):
       - Verify requested IP matches self.offered_ip (option 50).
       - Build ACK response same structure but type=ACK(5).
     - Session-awareness is not needed for v1 (single-guest). Every DISCOVER gets an OFFER for the fixed IP; every REQUEST for the expected IP gets an ACK.

5. Helper: `fn build_dhcp_response(...)` that populates the response buffer:
   - Takes xid, message_type, offered_ip, server_ip, subnet_mask, gateway_ip, dns_ip, lease_time, chaddr
   - Returns a Vec&lt;u8&gt; of the DHCP response
   - ~60 bytes for headers + ~40 bytes for options = well within the 548-byte minimum

6. Allocate the response buffer on the stack (548 bytes) and fill it in, then pass `send_slice`.

1. `pub fn spawn_dns_proxy(vsock_fd: RawFd) -> tokio::task::JoinHandle&lt;Result&lt;(), error::Error&gt;&gt;`:
   ```rust
   use std::net::ToSocketAddrs;
   use tokio::io::{AsyncReadExt, AsyncWriteExt};
   
   pub fn spawn_dns_proxy(vsock_fd: RawFd) -> tokio::task::JoinHandle<Result<(), error::Error>> {
       tokio::task::spawn(async move {
           let mut stream = tokio::fs::File::from_raw_fd(vsock_fd);
           let mut buf = vec![0u8; 512]; // DNS max wire size
           
           loop {
               // Read length-prefixed DNS query: u16 big-endian length, then that many bytes
               let mut len_buf = [0u8; 2];
               match stream.read_exact(&mut len_buf).await {
                   Ok(()) => {},
                   Err(e) if e.kind() == std::io::ErrorKind::UnexpectedEof => {
                       // vsock closed — shutdown proxy cleanly
                       return Ok(());
                   }
                   Err(e) => return Err(error::Error::Io(e)),
               }
               
               let query_len = u16::from_be_bytes(len_buf) as usize;
               if query_len > buf.len() || query_len == 0 {
                   continue; // malformed, skip
               }
               
               stream.read_exact(&mut buf[..query_len]).await
                   .map_err(|e| error::Error::Io(e))?;
               
               // Extract QNAME from DNS query (length-prefixed labels, null-terminated)
               // DNS header is 12 bytes, question follows
               let qname = extract_qname(&buf[..query_len]);
               let response = if let Some(domain) = qname {
                   resolve_dns(&domain)
               } else {
                   None
               };
               
               // Send response: u16 length prefix + DNS response bytes
               if let Some(resp_bytes) = response {
                   let resp_len = resp_bytes.len() as u16;
                   stream.write_all(&resp_len.to_be_bytes()).await
                       .map_err(|e| error::Error::Io(e))?;
                   stream.write_all(&resp_bytes).await
                       .map_err(|e| error::Error::Io(e))?;
               } else {
                   // Send SERVFAIL: same ID, flags=0x8182 (response + SERVFAIL)
                   let servfail = build_servfail_response(&buf[..query_len]);
                   let sf_len = servfail.len() as u16;
                   stream.write_all(&sf_len.to_be_bytes()).await
                       .map_err(|e| error::Error::Io(e))?;
                   stream.write_all(&servfail).await
                       .map_err(|e| error::Error::Io(e))?;
               }
           }
       })
   }
   ```

2. Helper `fn extract_qname(data: &[u8]) -> Option&lt;String&gt;`:
   - DNS header is 12 bytes. Question starts at offset 12.
   - Read length-prefixed labels: each label starts with a length byte (0-63), then that many bytes.
   - A null byte (0x00) terminates the QNAME.
   - Reconstruct the domain as "label1.label2.label3" (lowercase).
   - Return None if parsing fails (malformed, or compression pointer in question — rare for simple clients).
   - This covers ~99% of real DNS queries from busybox, musl, and glibc.

3. Helper `fn resolve_dns(domain: &str) -> Option&lt;Vec&lt;u8&gt;&gt;`:
   - Use `format!("{domain}:0").to_socket_addrs()` to trigger getaddrinfo.
   - Collect IPv4 addresses from the iterator.
   - Return None if no addresses found.
   - Build a minimal DNS response:
     - Copy the DNS ID from the query (first 2 bytes of the original query)
     - Flags: 0x8180 (QR=1, RD=1, RA=1, no error)
     - Question count: 1, Answer count: N (one per resolved IP)
     - Echo the original question section (from offset 12 to the first 0x00 label terminator + 4 bytes for QTYPE/QCLASS)
     - For each IPv4 address: NAME pointer 0xc00c, TYPE=1, CLASS=1, TTL=60, RDLENGTH=4, RDATA=IP bytes
   - Use `Vec` construction — no external DNS library needed.
   - Keep TTL at 60 seconds.

4. Helper `fn build_servfail_response(query_header: &[u8]) -> Vec&lt;u8&gt;`:
   - Copy first 2 bytes (ID from query)
   - Set flags to 0x8182 (QR=1, response code=SERVFAIL=2)
   - Set all 4 count fields to 0
   - Return 12-byte header only

      ```rust
          self,

      ) -> Vec<tokio::task::JoinHandle<std::result::Result<(), error::Error>>> {

                          net.poll(smoltcp::time::Instant::now());
                      }
                      Err(_) => {
                          return Err(error::Error::Netstack("AsyncFd error".into()));
                      }
                  }
              }
          }));

      }
      ```

| Boundary | Description |

| Netstack → Internet (via TCP re-origination) | Guest TCP connections are re-originated as host connections to external destinations |
