<objective>
**Plan 04-06: Guest-side DNS forwarder in vminitd**

**Purpose:** Implement the guest side of the vsock-based DNS proxy (D-07). vminitd (PID 1 inside the micro-VM) gets a second vsock listener on the configured DNS port (default 1235) and binds guest UDP:53. When a guest process sends a DNS query to UDP:53, vminitd reads it, sends it length-prefixed over vsock to the host, reads the host's DNS response, and sends it back to the UDP client. This completes the vsock DNS proxy split — host side in 04-04 `dns.rs`, guest side here.

**Output:** `dns_forwarder.rs`, updated `vminitd.rs`, updated `lib.rs`, rebuilt initrd.
</objective>

Create `crates/speck-guest/src/dns_forwarder.rs`:

1. **Module guard:** `#![cfg(target_os = "linux")]` — same as vsock_echo.

2. **`pub fn serve(dns_vsock_port: u32) -> io::Result<()>`:**

   a) **Create vsock listener on DNS port:**
      ```rust
      let listen_fd = unsafe { libc::socket(libc::AF_VSOCK, libc::SOCK_STREAM, 0) };
      // bind to VMADDR_CID_ANY, dns_vsock_port
      // listen with backlog 1
      // accept one connection → vsock_fd
      // close listen_fd
      ```
      Follow the exact same pattern as `vsock_echo::serve()` — socket, sockaddr_vm, bind, listen, accept, close listen.

   b) **Create UDP socket bound to 0.0.0.0:53:**
      ```rust
      let udp_fd = unsafe { libc::socket(libc::AF_INET, libc::SOCK_DGRAM, 0) };
      let addr = libc::sockaddr_in {
          sin_family: libc::AF_INET as u16,
          sin_port: 53u16.to_be(),   // port 53 in network byte order
          sin_addr: libc::in_addr { s_addr: 0u32 },  // INADDR_ANY
          sin_zero: [0u8; 8],
      };
      // bind
      ```
      Since vminitd is PID 1 (root), binding to port 53 succeeds.

   c) **Poll loop using `libc::poll()`:**
      ```rust
      let mut buf = [0u8; 512]; // DNS max wire size
      
      loop {
          let mut fds = [
              libc::pollfd { fd: udp_fd, events: libc::POLLIN, revents: 0 },
              libc::pollfd { fd: vsock_fd, events: libc::POLLIN, revents: 0 },
          ];
          
          let ret = unsafe { libc::poll(fds.as_mut_ptr(), 2, -1) };
          if ret < 0 {
              return Err(io::Error::last_os_error());
          }
          
          // UDP:53 has data — DNS query from guest app
          if fds[0].revents & libc::POLLIN != 0 {
              let n = unsafe {
                  libc::recvfrom(udp_fd, buf.as_mut_ptr() as *mut libc::c_void, 512, 0,
                      std::ptr::null_mut(), std::ptr::null_mut())
              };
              if n <= 0 { continue; }
              
              // Send length-prefixed DNS query over vsock
              let query_len = (n as u16).to_be_bytes();
              let mut written = 0usize;
              while written < 2 {
                  let w = unsafe {
                      libc::write(vsock_fd, query_len.as_ptr().add(written) as *const libc::c_void, 2 - written)
                  };
                  if w < 0 { return Err(io::Error::last_os_error()); }
                  written += w as usize;
              }
              
              written = 0;
              while written < n as usize {
                  let w = unsafe {
                      libc::write(vsock_fd, buf.as_ptr().add(written) as *const libc::c_void, n as usize - written)
                  };
                  if w < 0 { return Err(io::Error::last_os_error()); }
                  written += w as usize;
              }
              
              // Read response from vsock: u16 BE length prefix + DNS response bytes
              let mut len_buf = [0u8; 2];
              let mut r = 0usize;
              while r < 2 {
                  let n = unsafe {
                      libc::read(vsock_fd, len_buf.as_mut_ptr().add(r) as *mut libc::c_void, 2 - r)
                  };
                  if n <= 0 { return Err(io::Error::last_os_error()); }
                  r += n as usize;
              }
              
              let resp_len = u16::from_be_bytes(len_buf) as usize;
              if resp_len == 0 || resp_len > 512 { continue; }
              
              r = 0;
              while r < resp_len {
                  let n = unsafe {
                      libc::read(vsock_fd, buf.as_mut_ptr().add(r) as *mut libc::c_void, resp_len - r)
                  };
                  if n <= 0 { return Err(io::Error::last_os_error()); }
                  r += n as usize;
              }
              
              // Send DNS response to UDP client
              unsafe {
                  libc::sendto(udp_fd, buf.as_ptr() as *const libc::c_void, resp_len, 0,
                      std::ptr::null_mut(), 0);
              }
          }
          
          // Vsock data arriving without a prior query (rare/protocol error) — drain
          if fds[1].revents & libc::POLLIN != 0 {
              // Read and discard unexpected vsock data to keep the channel clean
              let mut drain = [0u8; 4];
              let _ = unsafe { libc::read(vsock_fd, drain.as_mut_ptr() as *mut libc::c_void, 4) };
          }
      }
      ```

3. **Error handling:**
   - All `libc` calls check for negative return values and convert to `io::Error::last_os_error()`.
   - If the vsock connection breaks (`read` returns 0 or error), return `Err` — the caller (vminitd main) should restart the DNS forwarder on next boot.

4. **Imports:**
   ```rust
   use std::io;
   ```

<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Guest user-space apps → Guest vminitd UDP:53 | Guest applications send DNS queries to UDP:53, trusting vminitd to resolve them |
| Guest vminitd → Host via vsock | DNS queries leave the guest over a vsock stream; the host resolves and returns responses |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06-01 | DoS | UDP:53 socket | accept | v1 processes one DNS query at a time. A flood of guest queries would queue in the UDP receive buffer; excess drops are acceptable. A future version can use concurrent processing. |
| T-04-06-02 | Spoofing | Guest name resolution | accept | Guest apps have no way to reach an external DNS resolver (netstack only routes TCP, not UDP:53). The only UDP:53 listener is vminitd, which proxies to the host. This is by-design confinement. |
| T-04-06-03 | Tampering | vsock wire format | mitigate | The length-prefixed wire format is validated: lengths >512 bytes are rejected. The vsock channel is trusted (host-agent to guest-agent, no untrusted intermediary). |
| T-04-06-04 | DoS | vsock thread panic | mitigate | The DNS forwarder runs in a `std::thread::spawn` — a panic in the forwarder does not crash the echo server. The top-level eprintln! logs the error. The guest reboots on next VM start. |
</threat_model>
