| Test client (bollard) → speck.sock | Tests connect as Docker clients; same trust boundary as production Docker CLI |
| SPECK_SOCK env var | Path to socket file; could be pointed at an arbitrary Unix socket |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-11-01 | Spoofing | SPECK_SOCK env var pointing to non-Speck socket | accept | Test-only code path; the test runner controls the env var; no production risk |
| T-06-11-02 | Information Disclosure | Integration test creates containers with test secrets | accept | Test containers use only "echo" commands and test env vars; no real secrets in test fixtures |
| T-06-11-03 | Denial of Service | test_events_stream_starts holds connection | mitigate | Test uses tokio::time::timeout(Duration::from_secs(5), stream.into_future()) to avoid blocking indefinitely |
</threat_model>
