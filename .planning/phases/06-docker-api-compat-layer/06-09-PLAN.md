  <action>
    Replace crates/speck-cli/src/commands/dashboard.rs entirely.

    Define App struct:
    - containers: Vec<ContainerRow> (ContainerRow: id: String, name: String, image: String, status: String, created: i64)
    - selected: usize
    - logs: std::collections::VecDeque<String> (max 200 lines)
    - should_quit: bool

    Define run_dashboard(speck_home: &Path) -> anyhow::Result<()>:
    1. crossterm::terminal::enable_raw_mode()? and crossterm::execute!(std::io::stdout(), crossterm::terminal::EnterAlternateScreen)?
    2. let backend = ratatui::backend::CrosstermBackend::new(std::io::stdout());
    3. let mut terminal = ratatui::Terminal::new(backend)?
    4. Setup panic handler to restore terminal on panic.
    5. Create tokio::sync::watch::channel::<Vec<ContainerRow>>(vec![]) for poll→TUI state.
    6. Spawn polling task: loop with tokio::time::sleep(Duration::from_secs(2)); call DockerClient::get("/containers/json?all=true"); parse JSON array into Vec<ContainerRow>; send on watch channel. On DockerClient error: send empty vec.
    7. Spawn log-tail task: on selected container change, call DockerClient::get(format!("/containers/{}/logs?tail=50&stdout=true&stderr=true", id)); parse response, send lines to App.logs.
    8. Main event loop: tokio::select! { event = tokio::task::spawn_blocking(crossterm::event::read) => handle keyboard, _ = tick_rx.changed() => refresh App.containers from watch }. On q/Esc/Ctrl-C: break loop.
    9. Keyboard: Up → selected = selected.saturating_sub(1); Down → selected = (selected + 1).min(containers.len().saturating_sub(1)); q → should_quit = true.
    10. terminal.draw(|frame| ui(frame, &app)):

    Define ui(frame: &mut Frame, app: &App):
    Layout: ratatui::layout::Layout::default().direction(Vertical).constraints([Constraint::Min(5), Constraint::Length(3)]).split(frame.area()). Upper area split Horizontal 50/50: left=container list table, right=log tail paragraph. Bottom area: status bar.

    Container list: ratatui::widgets::Table with header row (ID, NAME, IMAGE, STATUS in NEON_VIOLET style), rows from app.containers. Highlight selected row with Style::default().bg(Color::Rgb(20, 0, 40)).fg(Color::Rgb(0, 255, 255)). Use TableState for selection.

    Log tail: ratatui::widgets::Paragraph::new(log_lines_joined).wrap(Wrap { trim: true }). Show last N lines that fit in the panel height.

    Status bar: Paragraph with "↑↓ navigate  q quit  spk dashboard" in dim style.

    Cleanup in a defer pattern (use scopeguard or explicit cleanup): crossterm::terminal::disable_raw_mode(); crossterm::execute!(stdout(), crossterm::terminal::LeaveAlternateScreen).

    Note: The polling task and log-tail task must use a DockerClient constructed from speck_home.join("speck.sock") inside the spawned tasks. Clone the PathBuf.
  </action>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-09-01 | Tampering | Container log content with ANSI escape sequences | mitigate | Strip ANSI sequences from log lines before rendering in ratatui Paragraph (ratatui renders plain text; existing escape codes in logs could corrupt the TUI layout; use strip-ansi-escapes crate or simple regex to clean log lines) |
| T-06-09-02 | Denial of Service | Large log output in VecDeque | mitigate | VecDeque capped at 200 lines; pop_front when limit exceeded |
| T-06-09-03 | Denial of Service | Panic without terminal cleanup | mitigate | Install panic hook that calls disable_raw_mode() + LeaveAlternateScreen before printing panic message; standard ratatui pattern |
</threat_model>
