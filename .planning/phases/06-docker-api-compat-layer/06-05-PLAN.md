<objective>
Implement host-side port publishing: each `-p host:container` flag spawns a host TcpListener. Incoming connections are injected into the smoltcp stack via active-connect to the guest VM's fixed DHCP IP (172.16.0.2) on the container's port. No synthetic NAT — consistent with NET-01 and NET-06.

Purpose: Satisfies RUN-04. Port publishing reuses the existing smoltcp poll loop in speck-net, extending it with the reverse direction: host→guest via active-connect. The pattern mirrors the existing ReoriginBridge but in the opposite direction.

Output: PortPublishBridge in speck-net; PortMapConfig in GuestConfig; VmCommand::AddPortMap dispatch in vm_thread.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host network (macOS localhost) → host TcpListener | Untrusted clients on the host machine can connect to published ports |
| smoltcp active-connect → guest 172.16.0.2:container_port | Crossing from host user-space network stack into VM guest |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-05-01 | Spoofing | host_port < 1024 in PortMapConfig | mitigate | validate() in config.rs rejects host_port ≤ 1024; users needing privileged ports must configure OS-level port forwarding externally |
| T-06-05-02 | Denial of Service | TcpListener per published port | accept | At most ~50 published ports expected; each listener is a single OS socket; no DoS amplification risk beyond OS limits |
| T-06-05-03 | Tampering | ephemeral port exhaustion | mitigate | next_ephemeral_port wraps with used_ephemeral_ports in-use check; if all 16384 ephemeral ports (49152–65535) are in use, connection is rejected with tracing::warn! and the host TcpStream is dropped |
| T-06-05-04 | Information Disclosure | container_port in smoltcp active-connect | accept | container_port values come from GuestConfig set by the local user; no third-party influence on this value |
</threat_model>
