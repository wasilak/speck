<objective>
Create the size-rotating file appender module that the daemon uses for structured log output to `$SPECK_HOME/speck.log`.

Purpose: `tracing-appender 0.2.5` ships only time-based rotation policies — size-based rotation (10 MB / 5 files, per D3) requires a custom `struct SizeRotatingFileAppender` implementing `std::io::Write`. This plan gates the package install on a human legitimacy check (package was `[ASSUMED]` at research time) then creates the full `commands/logging.rs` module with `SizeRotatingFileAppender` and `init_daemon_logging()`.

Output: `commands/logging.rs`, updated `Cargo.toml`, updated `commands/mod.rs`.

DAEMON-04 NOTE: `spk restart` is explicitly deferred per CONTEXT.md §Deferred. DAEMON-04 is satisfied by the user running `spk down && spk up`. No `restart` subcommand is created in this plan or any Phase 09 plan.
</objective>

Implement SizeRotatingFileAppender with: pub fn new(dir: PathBuf, filename: &str, max_bytes: u64, max_files: usize) -> io::Result<Self> that initializes all fields and calls self.open_current(); fn open_current(&mut self) -> io::Result<()> that uses OpenOptions::new().create(true).append(true).open(self.dir.join(&self.filename)), reads f.metadata()?.len() into self.bytes_written, stores Some(f) in self.current; fn rotate(&mut self) -> io::Result<()> that iterates i from (self.max_files - 1) down to 1 via (1..self.max_files).rev(): computes src=self.dir.join(format!("{}.{}", self.filename, i)), dst=self.dir.join(format!("{}.{}", self.filename, i+1)), and if src.exists() and i+1 > self.max_files removes dst first, then renames src to dst; after the loop renames the current self.dir.join(&self.filename) to self.dir.join(format!("{}.1", self.filename)) if it exists; calls self.open_current().

The caller MUST bind the returned guard to a named variable (never use `let _ = guard;`) for the process lifetime — drop flushes the background writer thread.
