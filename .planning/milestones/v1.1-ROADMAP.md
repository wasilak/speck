# Milestone v1.1: Production Runtime

**Status:** ✅ SHIPPED 2026-07-06

## Overview

Make `spk` a real daily-driver container runtime. Closed all v1.0 gaps, added daemon lifecycle, VPN-proof DNS with live SCDynamicStore reload, corporate CA cert injection, config file with env/CLI/file precedence, VM resource controls, shell integration, `spk doctor` diagnostics, and Homebrew Formula distribution via ad-hoc signing.

## Milestone Summary

**Key Accomplishments:**
1. Containers run end-to-end — network egress, Unix socket, port bindings all wired (Phase 07)
2. Persistent config file with env > CLI > file > default precedence; VM resource validation (Phase 08)
3. Background daemon via launchd LaunchAgent re-exec; graceful SIGTERM shutdown (Phase 09)
4. `spk env` and idempotent `spk init` for bash/zsh/fish shell integration (Phase 10)
5. VPN-proof DNS: VM-internal proxy, SCDynamicStore live reload, split-DNS, NXDOMAIN→SERVFAIL (Phase 11)
6. Corporate CA injection into guest trust bundle and containerd hosts.toml, with fail-fast PEM validation (Phase 12)
7. `spk doctor` 8-check health suite + `spk doctor dns` hostname trace (Phase 13)
8. Homebrew Formula distribution via ad-hoc signed tarball with entitlement preserved (Phase 14)

**Key Decisions:**
- D-10: launchd LaunchAgent re-exec (not fork/daemonize crate) — UB after Mach port init
- D-09: DNS never binds host :53 — VM-internal proxy routes via SCDynamicStore
- D-11: CA certs tag as compile-time constant `speck-ca-certs` (not env var)
- D-14: `spk doctor dns` uses host getaddrinfo (same path as vsock proxy) — no container needed

**Issues Deferred:**
- DAEMON-04: First-class `spk restart` (use `spk down && spk up` for now)
- DNS-01/03/05: Live lsof + WARP + VPN toggle verification (deferred — requires VPN-connected machine)
- BREW-DEVID: Developer ID + pkg + notarytool + Cask (deferred — requires Apple Developer Program)

**Technical Debt:**
- `spk down` fails to stop processes not registered with launchd (direct `cargo run` sessions)
- No timeout on `update-ca-certificates` (non-fatal, but could block boot with 100+ certs)
- Testcontainers bollard conformance suite gated on codesign — not yet CI-verified
